# Carambole

An iOS French trainer with three books: *Fondations* (grammar), *En situation*
(spoken dialogues), and *Nuances* (visible-source reading and expression).

Current Book 3 status and verification are in the
[Nuances production handoff](docs/plans/2026-10-16-book-3-production-handoff.md).

## Requirements

- iOS 18.0+
