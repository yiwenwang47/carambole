# Gloss findings — module 02 (Le quotidien)

Segmenter note (carambole/Models/Situation.swift `segments`): matching is left-to-right, greedy longest at each position, and `norm` strips commas. So a 2-word key can span a comma and swallow the first word of a later phrase. Spaced punctuation (« Non ! ») is its own token and blocks a span.

The sentence means "No, later". The existing key "plus tard" = "later" never gets a chance. → FIX: rewrite sit_02_morning_d07 turns[1].text "Non, plus ___ : vers huit heures." → "Non !
