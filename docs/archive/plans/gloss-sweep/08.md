- [MUST] sit_08_exchange_d06 ("Vous pouvez rapporter le pull jusqu'à samedi.") — vous pouvez — "can you (polite)" in a statement → FIX: widen key: "can you (polite)" → "you can / can you? (vous)". The first senses ("he", "in") contradict the sentence, which means "there's one left" → FIX: add key {"fr": "il en reste", "en": "there's / there are … left (of them)", "audio": "sitw_il_en_reste", "firstSeen": null}.
