# Book 2, module 07 *Boulangerie et marché*: content matrix

**Arc:** Le quartier · **Cast:** One-off bakers and stallholders (vous); Léa, Théo, Inès, Karim (tu), M. Ferrand, Mme Dumas (vous) · **Goal:** Order bread and market food, ask quantities and prices, and say « c'est tout ».

Paper plan only: no French is authored yet. Overview, shared base glosses, rules and open questions: [arc 2 plan](2026-10-11-book-2-arc2-plan.md). The format follows the arc 1 matrices.

Each move is one element `sit_07_<move>` with 15 items in the fixed order d01 d02 s01 d03 d04 s02 … d09 d10 s05. Drill codes: `U` Comprendre, `R` Répondre, `C` Compléter, `M` Mot (target in brackets), `P` Choisir, `F` Corriger. Standalone drills run Construire, Choisir le ton, Corriger, Transformer, Mot en retour, in that order. **New** = first taught book-wide in this item (its `firstSeen`); it is always printed in a turn of that item (a server line or a printed learner line), never only in a gap or a built reply. **Reuse** = words taught earlier in the book (arc 1, café or earlier in this batch) that recur in the item; *Fondations* base words are not listed. A cue starting *Clarify* is the move's clarification or repetition dialogue; it is always face to face or a live call, never a text or a voicemail. In a Fill sketch the **first** choice is the correct one; vary its slot when authoring. Quoted French is a sketch for the author, not final text and never cue text. The English cue the author writes names the speaker and states tu or vous; standalone `place` labels below already match the cue's setting (judge class "place labels").
