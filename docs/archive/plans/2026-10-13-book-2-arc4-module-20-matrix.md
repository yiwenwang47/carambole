# Book 2, module 20 *Conseiller*: content matrix

**Arc:** Raconter · **Cast:** Inès, Léa, Théo, Karim (tu); Mme Dumas, M. Ferrand, an estate agent, phone-shop staff and Robin's manager (vous) · **Goal:** Ask for and give advice: recommend an option with a reason, warn, and react to the choice.

Paper plan only: no French is authored yet. Overview, shared base glosses, rules and open questions: [arc 4 plan](2026-10-13-book-2-arc4-plan.md). The format follows the arc 3 matrices.

Each move is one element `sit_20_<move>` with 15 items in the fixed order d01 d02 s01 d03 d04 s02 … d09 d10 s05. Drill codes: `U` Comprendre, `R` Répondre, `C` Compléter, `M` Mot (target in brackets), `P` Choisir, `F` Corriger. Standalone drills run Construire, Choisir le ton, Corriger, Transformer, Mot en retour, in that order. **New** = first taught book-wide in this item (its `firstSeen`); it is always printed in a turn of that item (a server line or a printed learner line), never only in a gap or a built reply. **Reuse** = words taught earlier in the book (modules 01–15, or earlier in this batch) that recur in the item; *Fondations* base words are not listed. A cue starting *Clarify* is the move's clarification or repetition dialogue; it is always face to face or a live call, never a text, the group chat or WhatsApp. In a Fill sketch (Compléter and Mot en retour) the **first** choice is the correct one; vary its slot when authoring. A model reply in brackets is a sketch: accept every valid order and the with/without « Pardon » variants. Quoted French is a sketch for the author, not final text and never cue text. The English cue names the speaker, states tu or vous (« vous = you all » in the group chat) and says "You're a woman." where the answer hinges on it; standalone `place` labels below already match the cue's setting. The Cast column gives an unnamed speaker's `role` (and its voice: male, or `voice: "female"`); `name` stays empty. Comprendre questions are not sketched: the author writes them, and **checks every `correct` index against the true choice** (arc 3 shipped 15 inverted keys).
