Each row is one card in the fixed D D S sequence. Drill codes: `U` Comprendre, `R` Répondre, `C` Compléter, `M` Mot (target in brackets), `P` Choisir, `F` Corriger. A Répondre drill only follows a server line, so the answer is never printed in a learner bubble before the reply slot.

## New words and their recurrence

Words whose `firstSeen` is null must be taught in *Fondations* (Book 1 answer sentences), or be an inflection of a verb Book 1 teaches (*voulez*, *prenez*, *fais*, *dis*). These four everyday words are absent from Book 1, so the café module teaches them:

| Word | First seen | Later dialogues (sample) | Mot / Mot en retour |
|---|---|---|---|
| bonjour | order d01 | order d02, d07, d10 | order d10 (M) |
| s'il te plaît | order d04 | order d08, size d04, size d08 | size d08 (M) |
| pardon | order d05 | order d07, size d03, size d05 | order s05 (Mot en retour) |
| merci | substitute d04 | substitute d07, d09, d10 | substitute d07 (M) |

| à la place | substitute d02 | substitute d04, d05, d07, d09 | substitute d05 (M), substitute s05 |

*Je voudrais* is a *Fondations* phrase (Book 1 builds « je voudrais un café, s'il vous plaît »), so it is a base word here, not a new one. Café nouns used as base words are all in Book 1: *café*, *thé*, *lait*, *table*, *soupe*, *gâteaux*, *chocolat*. Standalone items use only base words and words taught earlier in the module; the linter checks this.
