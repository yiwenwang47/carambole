# Book 2, module 05 *Fixer un rendez-vous*: content matrix

**Arc:** Arriver à Lyon · **Cast:** texts, a call (Théo, Léa, Inès), Mme Dumas (vous) on WhatsApp · **Goal:** Agree on day, time, place and people; confirm; move the plan; find each other on the day.

Paper plan only: no French is authored yet. Overview, rules and open questions: [arc 1 plan](2026-10-11-book-2-arc1-plan.md). The format follows the café matrices.

Each move is one element `sit_05_<move>` with 15 items in the fixed order d01 d02 s01 d03 d04 s02 … d09 d10 s05. Drill codes: `U` Comprendre, `R` Répondre, `C` Compléter, `M` Mot (target in brackets), `P` Choisir, `F` Corriger. Standalone drills run Construire, Choisir le ton, Corriger, Transformer, Mot en retour, in that order. **New** = first taught book-wide in this item (its `firstSeen`). **Reuse** = earlier-taught arc-1 words that recur in the item (base *Fondations* words are not listed). A cue starting *Clarify* is the move's clarification or repetition dialogue. Quoted French in a cue is a sketch of the line for the author, not final text. Every cue the author writes must still state tu or vous for each speaker.
