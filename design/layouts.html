Trois façons de composer l’écran

Layout only. Everything is grayscale so color doesn’t get in the way. Each direction takes one structural idea from the reference images: how the space is organized, not a surface effect. All three keep the circular progress ring, the light background and light grotesk type (Manrope 300 with Familjen Grotesk labels). Each phone scrolls. Swipe the rows sideways.

A

Texte courant: the screen is a typeset sentence

Status and actions are written as prose and set large and light. Controls sit inside the sentence, the way the photo sits inside the type in IMG_0941. The table of contents is one continuous paragraph: color carries state (black = done or current, pale = upcoming) and the current module gets a soft highlight. It is calm and bookish, and you read it more than scan it.

B

Affiche: a poster grid locked to the edges

The data is spread across the full width and pinned to the left and right margins, like “13  12  25” and “19 : 00 Uhr” in IMG_0942. Today’s numbers become the poster: 8 : 14. The 25 modules form a 5×5 matrix with a small ring in each cell, so the whole book is visible at once and the current module is the single black square. Strict, Swiss, and highly scannable.

C

Planche: a pinned-up board of unequal pieces

Each screen is a board of flat rectangles of different sizes and densities (black, white, pale gray, outline only), packed on a 4-column grid with tight gutters, like the moodboard in IMG_0940. Size carries importance: today’s session is the biggest piece, the current module is bigger than finished ones, and upcoming content is only an outline. Nothing overlaps.
