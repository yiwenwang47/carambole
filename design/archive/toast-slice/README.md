# Toast slice (codename)

Archived 2026-10-22. Variant D of the Book 3 option-tile comparison
(`archive/book3-nuances/design/book3-pilot/tile-alignment.html`, artifact
https://claude.ai/artifact/4QxiUx99V6PoCsqKj1pjbS). Not used for Book 3; the
user kept it for another purpose, not yet named.

**Design:** four answer rows in one column on the pale `tint` tray. Each row is
52 pt tall with a 16 pt radius, a 1.5 pt ink outline and 18 pt Manrope, and
rows are 8 pt apart. Text is left-aligned and vertically centred, so all
labels start on one left edge and forms that differ only at the ending line up
for comparison. Grading states follow the Book 1 colour idiom: right =
`tileOn` lime fill with no outline, wrong pick = dashed `fragile` outline, the
rest = `g3` outline with `g2` text.

**Height:** 4 × 52 + 3 × 8 = 232 pt of rows. A 2×2 grid of 96 pt tiles is
204 pt (28 pt less); a 2×2 grid of 64 pt tiles is 140 pt (92 pt less).

`toast-slice.html` is a standalone, tappable copy (tap to grade, tap again to reset).
